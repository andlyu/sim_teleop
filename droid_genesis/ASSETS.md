# Assets for the Genesis DROID port

The binary assets are **not stored in git** (see root `.gitignore`). The code expects them in
`droid_genesis/assets/`. Here's where each one comes from and how to recreate it.

## Source assets — HuggingFace dataset `owhan/DROID-sim-environments`
These are the original DROID sim assets used by `arhanjain/sim-evals`. Download them with:

```bash
# (from sim-evals' README) downloads scene*.usd, the robot USD, backgrounds, etc.
uvx hf download owhan/DROID-sim-environments --repo-type dataset --local-dir assets
```

Then copy into `droid_genesis/assets/`:
- **`franka_robotiq_2f_85_flattened.usd`** (~14 MB) — the real Franka + Robotiq 2F-85 robot.
  Loaded via `gs.morphs.USD(...)` in `franka_droid_env.py` (`ROBOT_USD`). Use this exact asset —
  do **not** substitute Genesis's bundled Panda hand (it changes the wrist-cam frame, gripper
  geometry, and grasp dynamics; see `~/.claude/skills/simulation` §0).
- **`scene1.usd`** — the DROID scene1 layout (used to extract the object meshes below).
- `billiard_hall_4k.hdr` — background HDR. **Not used** by the Genesis port: Genesis is
  rasterizer-only here and can't render HDR env maps, so the room is approximated with
  geometry. Listed only for completeness; skip the download if you don't need it.

## Derived assets — generated by us from `scene1.usd`
Extracted by world-baking the prim transforms into vertices (`UsdGeom.Xformable...
ComputeLocalToWorldTransform`), triangulated to OBJ, so they load at `pos=(0,0,0)` in their
true positions (see `~/.claude/skills/simulation` §4):
- **`scene1_rubiks_cube.obj`**, **`scene1__24_bowl.obj`** — the cube and bowl meshes. (The
  current env actually renders the cube as `cube_uv.obj` + `rubiks.png` and the bowl as a solid
  color, because the source materials are Omniverse MDL — RTX-only — so the extracted OBJs have
  no usable material/UVs. The extracted OBJs are kept for geometry reference.)

## Hand-authored assets
- **`cube_uv.obj`** (~1 KB) — a UV-mapped unit cube (all 6 faces wound CCW-outward) so a texture
  maps correctly. Genesis primitives have no UVs, hence a mesh. Small enough to regenerate
  trivially if lost.
- **`rubiks.png`** (~1 KB) — procedural Rubik's-cube face texture for `cube_uv.obj`.
- **`floor.png`** — wood floor texture applied to the table/floor surface.

## Where the live copy currently lives
On the GPU box: `/root/sim-evals/assets/` (downloaded from the HF dataset above). The local
working copy was in `droid_genesis/assets/` (gitignored). If you need the exact byte-identical
derived OBJs/PNGs again, they can be re-extracted from `scene1.usd` with the procedure above.
